# Invincible Goal

A browser-based 3D rugby league goal-kicking prototype.

## Prototype loop

- Ten kicks, each wider, longer, or windier than the last.
- Press space, click, or tap once to set power.
- Press space, click, or tap again to set direction.
- A missed kick ends the run. The target is 10 straight.

## Local development

```sh
pnpm install
pnpm run dev
```
